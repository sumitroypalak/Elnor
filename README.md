# Elnor 📝

A simple Android note-taking app.

Features

- Create notes
- Big screens: on a tablet or an open foldable the notes list stays on the left and the note opens on the right (tap a note to switch, the one that was open is saved first). The notes grid has more columns on wide windows, and the text screens keep a comfortable width. A phone held sideways keeps the one-page layout. On a tablet or an open foldable the tabs and the round "+" button move from the floating bottom bar to a rail on the left edge; every phone, also one held sideways, keeps the bottom bar
- Edit notes. The keyboard opens at once only for a new note; an existing note opens without the keyboard, so it can be read in peace. Tap the text to start typing
- Undo and Redo buttons at the top of the note page (a word at a time)
- "Last edited" date and time under the title of a note
- Word and character count under the text of a note, e.g. "12 words · 68 characters" (works for Bengali too)
- Share a note (share button at the top of the note page: send the title and text to WhatsApp, e-mail, messages or any other app)
- Basic formatting (Markdown): while you write, buttons above the keyboard make text **bold** (B), a heading (H: press again for a smaller heading, again to remove it), a bullet list (•) or a numbered list (1.). Select text first to format it, or put the cursor in a word or on a line. Enter inside a list starts the next item, Enter on an empty item ends the list. The formatting is plain text in the note (`**bold**`, `# Heading`, `- item`, `1. item`), so you can also type it yourself; the marks stay visible but dimmed while you edit, and the notes list shows the text without them
- Checklists: the ☑ button above the keyboard turns the selected lines (or the line of the cursor) into checklist items, `- [ ] milk` and `- [x] eggs`; press it again on a whole checklist to take the boxes away. Enter on an item starts the next empty box, Enter on an empty box ends the list. In the Preview (eye button) every item has a real check box: tap it to tick or untick the item, which is saved in the note at once (the ticked text is dimmed and crossed out). In the editor the boxes stay visible as text, so you can also type `[x]` yourself. In the notes list an empty box is shown as ☐ and a ticked one as ☑. Nothing is stored besides the text, so search, share, copy and Backup keep working; a note with such lines opens fine in any Markdown app
- Links between notes: write `[[Name of another note]]` in a note and it is a link to that note. The name is the title of the note (or, for a note without a title, its first line, the same name the notes list shows). Capital and small letters and extra spaces do not matter, and Bengali works. The easy way: the `[[` button above the keyboard opens a list of your notes (with a search field); tap one and the link is written at the cursor (or in place of the selected text). Links are shown in colour with an underline. While the cursor is in a link, a "Go to ..." button above the keyboard opens that note; in the Preview (eye button) a tap on the link opens it. The note that is open is saved first. If no note has that name, Elnor asks "Create it?" and opens a new note with that title, so a typo never makes a note by itself. If two notes have the same name, the one with the same capital letters, then one that is not archived, then the most recently changed is opened. Archived notes can be linked to and opened, notes in the Trash cannot. The links are only text: nothing else is stored, so search, share, copy and Backup are not changed. If you rename a note, links that still use the old name point to nothing (they offer to create a note with the old name). The Archive page shows its notes without link buttons, and a link there is not followed
- Preview (eye button at the top of the note page): shows the note as a reading page. The formatting marks are hidden: the title and the `#` lines are big headings, bold words are bold, and bullet and numbered lists are drawn as lists (a deeper list level sits further to the right). Web links, e-mail addresses and phone numbers can be tapped to open them (Open, Email, Call work like in the editor). A pencil button in the same place goes back to editing. Undo, Redo and Find are only there while editing, and the keyboard and the Find bar close when the preview opens. The preview only changes what is shown: the note, the saving and the Backup are not touched, and every note page starts in the editor
- Tags (labels): write `#work`, `#shopping` or `#কাজ`, `#বাজার` anywhere in a note (the title too) and it is a tag. Tags are shown in colour while you write and in the preview. A tag is `#` and a word right after it, and it ends at the first space or sign (`#work,` is the tag `work`). It needs at least one letter, so `#1` is not a tag, and `# Heading` (with a space) is still a heading. Text inside a web link (`example.com/#top`) is never a tag. Capital and small letters are the same tag (`#Work` = `#work`). On the home screen a row of buttons under the search field lists every tag with the number of notes that have it, the most used first. Tap one to show only the notes with that tag (the same search text still works together with it), tap it again to show all notes. A tag that no note has any more is taken off by itself. Typing `#কাজ` in the search field also finds notes by their tag, as the search looks at the whole text. Nothing is stored: tags are calculated from the text, so the Backup and the database are not changed
- Links in a note are found by themselves: web links (http://, https://, www.), e-mail addresses and phone numbers (also Bengali digits) are shown in colour with an underline. Put the cursor in one and a button above the keyboard appears: Open, Email or Call (Call opens the dialer with the number filled in; you press call yourself). Nothing is stored, the links follow the text
- Find in a note (search button at the top of the note page): type a word and every place of it in the text is highlighted in yellow, the chosen one in orange, with a counter like "2/5". The up and down buttons (or the Search key of the keyboard) move to the previous and the next place and put the cursor there. Upper and lower case do not matter, and Bengali works (also the two ways of typing য়). Only the text of the note is searched, not the title. Back or the X closes the bar. Nothing is stored or changed in the note
- Save a note as a file (share button at the top of the note page > "Save as .txt" or "Save as .md"): Android's Save screen asks where to keep it. The file name is made from the title (or the first line), and the file is UTF-8, so Bengali works. A .txt file has the title and the text without the formatting marks; a .md file has the note exactly as written, with the title as a "#" heading on top. Nothing in the note changes. The file is not encrypted, so it is outside the App lock
- Copy the text of a note (copy button at the top of the note page: title and text go to the clipboard)
- Tasks (Task tab at the bottom): a to-do list with a check box for each task. The round "+" button adds a task; tap a task to change its title or deadline, or to delete it. A deadline is a whole day (Today, Tomorrow, or any date from the date picker) and can be removed again. A task can also have a reminder: "Set reminder" in the task dialog opens the date picker and then the time picker, and at that minute Elnor shows a notification with the task title (tap it to open Elnor). The reminder is separate from the deadline, so a task can have one, both or none, and it can be removed again. A time that has already passed cannot be chosen. Checking a task off, deleting it, or removing the reminder cancels the notification; unchecking a task brings its reminder back if the time is still to come. Reminders are set again after the phone restarts or Elnor is updated. On Android 13 and newer Elnor asks for the notification permission the first time you set a reminder; on Android 12 and newer, if "Alarms & reminders" is off in the phone's settings for Elnor, the notification may come a few minutes late. While the App lock is on, the notification says only "Task reminder" and does not show the title Open tasks are listed first, the nearest deadline on top; tasks without a deadline come after them; finished tasks are at the bottom with a line through them. Checking a task off gives a light vibration (when the phone's touch feedback is on) and a message with "Undo" at the bottom, so a task checked by mistake can be opened again with one tap; unchecking a task needs neither. A deadline that has passed is shown in red as "Overdue". The filter chips All / Active / Completed show how many tasks each one has, and "Clear completed" deletes all finished tasks after you confirm. Tasks are not part of Backup & restore yet
- Collections (Collection tab at the bottom): folders for your notes and tasks. On this tab the round "+" button makes a new collection (a name of up to 40 characters; the same name twice, capital letters not counted, is not allowed). The tab lists the collections A to Z with how much is in each ("3 notes · 2 tasks"); tap one to open it. Inside, the notes and the tasks of that collection are listed: tap a note to open and edit it (Back brings you back to the same collection), tick a task, or press the X of a row to take it out of the collection (it is not deleted). The top has Rename and Delete; deleting a collection keeps all its notes and tasks, they are just in no collection any more. Put a note in a collection with "Move to collection" in its three-dot menu (the question also has "New collection", which makes one and puts the note in it at once); put a task in one with the "Collection" buttons in the task dialog (they appear when at least one collection exists). A note or a task is in one collection at most. Saving a note, archiving it or moving it to the Trash does not change its collection, and "Duplicate" keeps the copy in the same collection. The Collection tab shows the notes of the home list (not the Archive, not the Trash). Collections are not part of Backup & restore yet (like tasks)
- Save text from other apps: use "Share" > Elnor in any app, or select text and choose "Save to Elnor" in the menu that appears. The text becomes a new note (a shared subject, like a web page title, becomes its title) and a short message "Saved to Elnor" appears. Elnor does not open, so you stay in the app you were reading. It also works while the App lock is on, because nothing of your notes is shown
- Quick note: start a new note without opening Elnor first. Touch and hold the Elnor icon on the launcher and choose "New note", or add the "New note" tile to the Quick Settings panel (swipe down twice, tap the pencil / edit button, drag "New note" in). Both open an empty note at once, also from Settings or the Task tab; a note that is open is saved first. If the phone is locked, the tile asks to unlock the phone first, and the App lock of Elnor still covers your notes until you unlock. On Android 13 and newer, Settings > Quick note > "Quick Settings tile" adds the tile with one tap: the system asks "Add tile?" and puts it in the panel, so there is no need to find it by hand (older phones use the way above)
- Font size (Settings > Appearance > Font size): Small, Medium (the default) or Large for all text in the app, remembered. Each name is shown in its own size in the dialog, and the change is seen at once. Headings in notes and the space between lines grow with it, which helps when reading Bengali. It is added on top of the phone's own font size setting
- Haptic feedback (Settings > Appearance > Haptic feedback, on by default): a light vibration that tells what happened. A tick for small touches (formatting buttons, Undo / Redo, tabs, the "+" button, sort, list / grid, one more selected note, Select all); a firmer "done" tick when something was done (Pin / Unpin, Archive, Delete, Restore, Delete forever, Empty trash, a finished backup or restore, a task checked off); a long vibration when touch and hold starts the selection of notes; and a "no" vibration when something failed (a note that could not be saved, a backup or restore that failed, an unlock that failed). Selecting many notes and pinning them at once vibrates once. Nothing vibrates while typing, searching or scrolling. It needs no permission and also follows the phone's own touch feedback setting, so it stays quiet when that is off. Android 11 and newer have special "done" and "no" ticks, older phones get the closest ones
- Predictive back (Android 14 and newer; on Android 13 only with "Predictive back animations" in the developer options), in the style of the photo viewer of Google Photos: swipe Back from the edge and the page that closes gets smaller, follows your finger (to the side it was pulled to, and up or down), gets round corners, and fades away at the end, while the screen behind it is already there and grows to its full size. Let go to go back, or drag back to stay. It works for the note page (also in the Archive) and for Settings, Archive, Trash, Backup and App lock; the Back arrow and the Back button play the same animation without the finger. Closing a note by Back still saves it, and Back still closes the Find bar, the side menu, a selection and the Task / Collection tab first, as before. On the home screen the system shows its own preview of going back to the phone's home. On older Android versions nothing changes
- Default dark look: a dark blue-grey page (#121318) with slightly lighter cards, search field and bottom bar (#1E1F25), light blue accents (#B0C6FF) and a deep blue selected tab (#00419C). Text is a soft grey-white (#E2E2E9). The light theme uses the same blue palette: a soft tinted page (#F4F3FA) with white cards, and a blue accent (#0058CA). The bottom bar follows the theme: white with a thin edge in the light theme (selected tab in strong blue with white text), dark in the dark theme. The round "+" button is in the accent color in both themes (blue with a white plus in the light theme, light blue in the dark theme), so the main action stands out
- Pure black (AMOLED) theme (Settings > Appearance > Theme > "Pure black (AMOLED)", the fourth choice): the dark theme with a page of pure black (#000000), so the pixels of an AMOLED screen are switched off, which saves battery and looks deeper at night. It is always dark, whatever the phone uses. Only the page is black: the cards, the search field and the bottom bar keep their dark colors (#1E1F25) and stand out from it, and the text and the accents are the same as in the dark theme. It also works together with Dynamic color (the page is black, the other colors follow the wallpaper). The choice is remembered, and the status and navigation bars match it
- Dynamic color (Settings > Appearance > Dynamic color, Android 12 and newer): the colors of the app follow the colors of the phone's wallpaper, in the light and in the dark theme. The note cards and the bottom bar take their colors from it too, and the text on them stays easy to read on any wallpaper. It is off by default, so an update never changes the look by itself. On older Android versions the switch is not shown and the Elnor colors are always used
- Side menu (hamburger button): large app name and outlined icon rows for Settings and Trash, with a rounded highlight on the pressed row
- Sort notes (sort button next to "Your notes", remembered): last edited newest or oldest first, or by title A to Z or Z to A. Pinned notes always stay first
- Select many notes: touch and hold a note, then tap more notes. The bar at the top then has Pin / Unpin, Archive and Delete for all selected notes at once, and "Select all" in its three-dot menu. Back or the X ends the selection
- Archive: keep a note without seeing it on the home screen (three-dot menu of a note, or the selection bar). Archived notes are not in the home list, but the search finds them (marked "Archived"). Open them from the side menu > Archive: search there, tap a note to read and edit it (it stays archived), unarchive it or delete it. "Undo" appears right after archiving
- Pin notes: "Pin" in the three-dot menu of a note keeps it at the top of the list ("Unpin" to undo)
- Show notes as a list or as a two-column grid (button next to "Your notes", remembered)
- Smooth screen changes: Settings, Archive, Trash, Backup and App lock open with a small slide to the left and a fade (and go back the other way). A note opens with a small rise and fade, and the Note / Task / Collection tabs, the top bar of the selection, the empty and loading states fade into each other. The list / grid switch of the notes "fades through": the old view fades out quickly, then the new one fades in while it grows a little (300 ms), so the two are never seen on top of each other. The Find bar, the formatting buttons, the Open / Email / Call button and the recent searches slide or fade in and out, and a task that is checked off moves to its new place. All of it is 180 to 250 milliseconds, set in one file (Motion.kt), and it follows the phone's "Remove animations" setting. The lock screen only fades away when the app is unlocked, it never fades in, so the notes are never seen for a moment when the app locks
- Smooth list animation: when a note is added, deleted, archived, pinned or the sort order or the search changes, the cards fade in and out and slide to their new place instead of jumping (both in the list and in the grid)
- Smooth movement in the other lists too: in the Trash, the Archive, the Collection tab and the Task tab a card that is restored, deleted, unarchived, added or renamed fades and slides to its place and the others close the gap, instead of jumping. A note in the Trash opens and closes its whole text softly when tapped. The list of collections and an open collection slide into each other. The empty messages ("Trash is empty", "No tasks yet", ...) fade in. "Clear completed" in the Task tab opens and closes softly. The bar of the selection in the Trash and the Archive fades like on the home screen. In Settings the choice under Theme and Font size fades into the new one, and the pressed row of the side menu fades in and out. All of it takes its times from Motion.kt and follows the phone's "Remove animations" setting
- Delete notes (they go to the Trash first). There is no confirm question: the note is moved to the Trash at once and a message "Note moved to Trash" with "Undo" stays at the bottom for about 10 seconds. "Undo" takes the note out of the Trash again, exactly as it was (also pinned, if it was pinned). It works the same from the three-dot menu of a note, from the selection bar (one message for all selected notes), from the Archive and from the delete button of the note page. Deleting for good in the Trash still asks first, because that cannot be undone
- Trash: restore a note, delete it for good, or empty the Trash
- Each note in the Trash shows how long is left before it is deleted for good ("Deleted for good in 12 days", "tomorrow" or "today"). With 3 days or less left the line is red, so a note can still be restored in time
- Notes in the Trash are deleted automatically after 7, 30 (the default) or 90 days, counted from the day they were moved there. Choose it in Settings > Trash > "Keep deleted notes for". Choosing a shorter time asks first, because notes that have been in the Trash longer than that are deleted for good at once. A longer time only keeps notes longer
- Backup & restore (Settings > Backup & restore): save all notes (also the ones in the Trash and the Archive) into one `.json` file in a place you choose, and add the notes of such a file back. Restoring only adds notes: nothing that exists is changed, and importing the same file twice makes no copies. The file is not encrypted.
- App lock: unlock with fingerprint, face or the phone's own screen-lock PIN (Settings > App lock). It locks immediately, after 1 minute or after 30 minutes. Elnor has no PIN of its own. While the App lock is on, screenshots and screen recording are blocked and the Recent Apps preview of Elnor is blank, so notes cannot be seen there. The notes database is also kept out of Google cloud backup and adb backup: use Backup & restore to move notes to another phone.

About

Elnor is designed to make note-taking simple and convenient.
